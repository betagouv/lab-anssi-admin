# pgdump (cc)

dump database postgresql from clevercloud infrastructure

# Usage

```sh
	Usage: ./pgdump.sh <options>
	* get list from clever cloud
	--list
	* size all databases: --size files.txt
	--size
	* dump all databases: --dump files.txt
	--dump
	* get all database and dump them
	--dump-auto
	* execute in specific db: --execute <instance_id> "<sqlcmd>"
	--execute
	* More blahblah:
	-v|--verbose
	* Myself :-D
	-h|--help

	--org
	--rebound-instance
	--identity-file
	--output-dir
```
